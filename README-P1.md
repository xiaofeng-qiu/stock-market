# 预判验证 App — P1 运行说明

P0 是纯前端闭环；P1 加了 RSS 自动订阅、标的自动标注、实时行情自动验证、定时提醒与 Web Push，因此需要一个小后端服务。

## 启动

### 方式一：手机/局域网访问（推荐，单端口）

```bash
cd prediction-app
npm run start:prod
```

这条命令先构建前端，再用后端在同一端口托管前端 + API（默认 4300）。电脑和手机连同一个 WiFi，手机浏览器打开：

```
http://<电脑内网IP>:4300
```

例如本机是 `http://192.168.1.3:4300`。内网 IP 可用 `ipconfig`（Windows）或 `ifconfig`（Mac/Linux）查。

**局域网是 HTTP，能力限制：**
- ✅ 新闻拉取、记预判、自动验证、复盘统计——全部可用
- ✅ 添加到主屏幕（Android Chrome 可用；iPhone Safari 也能加，但功能受限）
- ❌ Service Worker 离线缓存——HTTP 下不注册（localhost 除外）
- ❌ Web Push 推送——需要 HTTPS

开发阶段完全够用。等要全面验证 PWA/推送时，再发布到 HTTPS 链接。

### 方式二：本机开发（前后端分离，热更新）

```bash
cd prediction-app
npm run start:all
```

一条命令同时启动：

- 前端：http://127.0.0.1:4200（API 通过代理转发到 4300）
- 后端：http://127.0.0.1:4300

也可分开启动：`npm start`（前端）、`npm run server`（后端）。

首次用 PWA / 推送请用**生产构建 + HTTPS 或 localhost**：

```bash
npm run build
cd dist/prediction-app/browser && npx http-server -p 4200
```

## P1 新增功能

### 1. RSS 自动订阅
- 顶栏 ⚙ → 信源设置，默认已配「玖峰投研精选」
- 新闻页点「↻ 拉取」从所有启用的源抓新闻，按链接 + 标题去重
- 连续失败 3 次的源自动暂停，避免无效请求
- 手动录入入口保留，作为 RSS 挂掉时的兜底

起步推荐源（已验证可访问）：
- 玖峰精选 `https://xiaoxi.report365.com.cn/feed.xml`
- 玖峰日报 `https://xiaoxi.report365.com.cn/feed/daily.xml`
- 每日财经 `https://findailys.com/feed.xml`

财联社公告等 RSSHub 路由需自建实例（公共实例常限流）。

### 2. 标的自动标注
- 从标题/摘要识别股票名、6 位代码、指数、板块词和宏观信号词
- 识别结果作为**候选标签**，需你点选确认，不会自动写入预判
- 新闻卡片上直接确认，确认后「记预判」自动带上标的

### 3. 实时行情自动验证
- 验证页点「↻ 自动验证」，从待验证预判提取代码，调后端拿实时行情
- 重要约束（保证判定可信）：
  - **只验证目标交易日 = 今天的预判**——实时行情只反映当日
  - **T+N 窗口跳过**——需到期后手动补收盘价
  - 行情数据不缓存，每次都取实时值
- 非当日或历史预判仍用「导入行情」手动对账

### 4. 定时提醒与推送
- 信源设置里开启提醒，浏览器授权通知权限
- 后端每分钟检查：到点时推送「有预判等待验证」（09:31 开盘 / 15:05 收盘 / T+N 日）
- 提醒时点由待验证预判自动生成，验证后自动移除
- iOS 需先「添加到主屏幕」才能收到推送；推送只做提醒，App 内列表才是可靠入口

### 5. PWA
- 按数据类型分流缓存：App 壳预缓存后台更新、新闻网络优先缓存 7 天、**行情与验证结果禁止缓存**
- 版本更新提示 + 离线兜底页
- 自定义 SW 包装 Angular 官方 SW 以支持推送

## 验证

```bash
npm run verify:p1
```

覆盖行情代理、RSS 解析、标的标注、交易日历、VAPID 配置，共 20 项。

## 架构说明

数据存在浏览器 localStorage（单用户），服务端不持有业务数据。因此：
- 定时任务只负责**推送提醒**，不做验证判定
- 验证判定仍由前端在拿到实时行情后执行，公式与 P0 一致
- 这样既实现了到点提醒，又避免服务端用缓存旧价格算出假分数

后端只提供四类能力：RSS 解析代理（规避跨域）、行情代理、交易日历、推送订阅与发送。VAPID 密钥本地生成在 `server/data/vapid.json`，无需任何外部账号。
